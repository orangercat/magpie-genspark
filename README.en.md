# Magpie · Reuse Your Genspark App Sign-In

[简体中文](./README.md) | English

<img src="./icon.svg" width="32" height="32" alt="Genspark App sign-in plugin icon">

For Genspark Super App on macOS. The plugin reads the credentials generated by the App for GenCode without modifying them. It reads the file again for every request to pick up credential changes. It does not decrypt `session.enc` or store a copy of the actual API key.

## Providers

One plugin exports two providers. Connect each separately; both use the same local Genspark App account and credit balance:

| Provider ID | Display name | Protocol | Plugin export |
| --- | --- | --- | --- |
| `genspark-llm-proxy` | Genspark GenCode | Chat Completions | `GensparkApp` |
| `genspark-gemini-proxy` | Genspark GenCode Gemini | Gemini | `GensparkGeminiApp` |

Both providers use the Genspark brand icon: white sparkles and a horizontal bar on a black background. It comes from the `genspark` icon in the App's built-in `SpaceGlyph` component (2026-10-25). The image is embedded in the package metadata, so displaying it requires no request to an image server.

## Usage

Install Magpie and Genspark Super App first. Sign in to the Genspark App and open GenCode. Then run the following commands. If `magpie` is not on your PATH, use `/Applications/magpie.app/Contents/MacOS/magpie` instead.

```sh
magpie plugin add github:orangercat/magpie-genspark
magpie plugin login genspark-llm-proxy
magpie plugin login genspark-gemini-proxy
magpie plugin
magpie quota genspark-llm-proxy
magpie quota genspark-gemini-proxy
```

Alternatively, add `github:orangercat/magpie-genspark` on Magpie's Plugins page, then click “复用 Genspark App 当前登录” (reuse the current Genspark App sign-in) for each provider. No API key entry is required. Magpie stores only a binding marker and the account email. Each machine uses its own local Genspark App session; there is no need to copy credentials between machines.

To update installed plugins:

```sh
magpie plugin update
```

You can also clone this repository and run `magpie plugin add .` from its root to load it as a local folder plugin.

Sign-in, model discovery, and balance queries all request `/api/tool_cli/opencode-config`. Context limits, input/output types, reasoning variants, and default options come from that catalog. Disabled or deprecated models and disabled variants are excluded.

`magpie quota` shows the bound account's plan and live credit balance for each Genspark provider. Both providers share the same Genspark App account.

## Development and Validation

The project uses Node.js ES modules and built-in APIs, with no additional npm dependencies. Tests require Node.js and npm.

| File | Purpose |
| --- | --- |
| `index.mjs` | Both plugin exports, credential reading, account binding, model mapping, and request forwarding |
| `test.mjs` | Regression tests using temporary credentials and mocked fetch |
| `package.json` | Package entry point, published file list, and test command |
| `icon.svg` | Shared SVG icon source; `magpie.icon` in `package.json` embeds the same content |

Run from the repository root:

```sh
npm test
```

Local validation on 2026-10-24 passed all 8 checks. They cover keyless sign-in, model and variant filtering, both providers' balance queries and request forwarding, credential rotation, account-switch rejection, invalid credentials, and catalog service failures. Tests do not read real local credentials, send network requests, or consume Genspark credits.

For a live integration check after connecting a provider:

```sh
magpie provider test genspark-llm-proxy gpt-5.4-nano
```

This command makes a real model request and consumes Genspark credits. The model must be available in your account's current catalog. The plugin does not send inference requests during installation or sign-in.

## Troubleshooting

| Symptom | Action |
| --- | --- |
| Credentials cannot be read or are invalid | Sign in to the Genspark App, open GenCode, and reconnect the affected provider. Check whether the App still uses the credential path listed below. |
| The current account differs from the bound account | Confirm the account in the App, then reconnect both providers separately. |
| The catalog request returns 401 | Sign in again in the App, then reconnect the plugin. |
| The catalog request returns 403 while the App works | Check Magpie's proxy settings and actual network route first. Follow the steps below; 403 alone does not prove that credentials have expired. |
| The catalog request returns another HTTP error | Check the network and Genspark service status. The plugin reports a service error rather than treating it as an expired sign-in. |
| Magpie estimates the dollar cost as zero | The catalog prices are in credits, and the plugin does not convert them to dollars. Use `magpie quota` to check the credit balance. |

### Catalog HTTP 403: Check the Proxy

During a cross-machine installation on 2026-10-25, the user confirmed that the credential file was readable and its fields were valid. GenCode worked inside the App after signing in again, but Magpie still reported a model catalog request failure with HTTP 403. The user identified a proxy issue and restored access after correcting it. This explains that incident; it does not mean that every 403 is caused by a proxy.

Follow these steps:

1. Confirm that the plugin is loaded and read the full error. A missing file, insufficient read permissions, or invalid JSON produces “无法读取 GenCode 登录凭据” (cannot read GenCode sign-in credentials). A catalog HTTP 403 occurs at the subsequent network request stage.
2. Confirm that the local credential file is readable, `base_url` is `https://www.genspark.ai`, and `api_key` is a nonempty string. This checks the file format, not whether the server still accepts the credential. Do not share or copy the key.
3. Open GenCode in the Genspark App and confirm that its model list loads. If the App also fails, resolve its sign-in or network problem first. If only Magpie fails, check Magpie's global proxy, the provider or account proxy settings, and the proxy client's domain routing rules. The App working does not guarantee that both programs use the same network route.
4. Switch Magpie to a known working proxy or network route, then reconnect both providers. There is no need to reinstall the plugin or change the request URL.

```sh
magpie plugin login genspark-llm-proxy
magpie plugin login genspark-gemini-proxy
```

The catalog request is `GET https://www.genspark.ai/api/tool_cli/opencode-config`. It sends the local credential in the `x-api-key` header. Both providers and balance queries use this endpoint. If this step fails, no inference request has been sent yet.

If 403 persists after adjusting the proxy, inspect the response, account access permissions, and Genspark service status. Do not assume the proxy is responsible. Share only the error and necessary response details, never the credential file or request headers containing the key.

## Limitations

- App credentials are read from `~/Library/Application Support/gensparkaio/spaces/gencode/gsk/profile/config.json`. This is an internal App path and may change after an upgrade.
- If the App switches accounts, the plugin rejects the old account binding. Reconnect both providers. The catalog is cached in memory for at most 60 seconds; a key change triggers an immediate account check.
- The App manages credential renewal. The plugin does not issue or refresh credentials itself. A catalog response of 401 is reported as an expired sign-in; inference responses are passed directly to Magpie.
- Catalog prices are in Genspark credits, not dollars. The plugin therefore does not enter them as dollar prices. Magpie's estimated dollar cost is zero, which **does not mean the service is free**. Genspark determines the actual charges.
- Requests are restricted to the model proxy paths on `https://www.genspark.ai`. Redirects are not followed. The plugin does not log API keys or conversation content.
- Only macOS is currently supported. Windows and Linux have not been adapted or validated.
- The plugin does not change any agent's model selection or add dependencies. This is an unofficial plugin.
